### Lists

Tot nu toe heb je variables gebruikt om waarden te bewaren.

```python
name = "Alex"
age = 16
```

Iedere variable verwijst hier naar één waarde.

Soms wil je meerdere waarden bij elkaar bewaren. Daarvoor kun je in Python een **list** gebruiken.

```python
names = ["Alex", "Sam", "Robin"]
```

De waarden in een list noemen we **items**.

De list `names` bevat hier drie items:

```text
Alex
Sam
Robin
```

Een list wordt geschreven met vierkante haken `[]`. De items worden van elkaar gescheiden met komma's.

Een list kan ook leeg beginnen:

```python
names = []
```

De variable `names` verwijst dan naar een list waarin nog geen items zijn opgeslagen.

Een list maakt het zo mogelijk om meerdere waarden die bij elkaar horen samen in één structuur te bewaren.
