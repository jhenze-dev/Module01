### Conditions

Een Boolean expression kan als **condition** worden gebruikt.

Een condition bepaalt of bepaalde code wel of niet wordt uitgevoerd.

Bijvoorbeeld:

```python
temperature < 20
```

Python kan deze condition evalueren.

Het resultaat is altijd één van twee Boolean values:

```python
True
False
```

Een condition kan vervolgens worden gebruikt om te bepalen welke
instructies een programma moet uitvoeren.
