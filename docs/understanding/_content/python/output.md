### Output

Met `print()` kan een programma informatie tonen.

```python
print("Hello")
```

De uitvoer is:

```text
Hello
```

De tekst die moet worden weergegeven staat tussen aanhalingstekens.

Je kunt meerdere `print()`-instructies gebruiken:

```python
print("Good morning")
print("Have a nice day")
```

De uitvoer is:

```text
Good morning
Have a nice day
```
